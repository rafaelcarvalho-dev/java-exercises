# Java Exercises

Solutions to the Java exercise lists from the **Programming Language** course of the Systems Analysis and Development (ADS) program at FATEC Prof. João Mod, in Guaratinguetá, Brazil.

> **Note:** This repository was created for study purposes only.

Built with plain Java, focusing on programming logic, problem solving, and clean, readable code.

## What's inside

- Seven exercise lists, one folder per list (`list-01` to `list-07`)
- Each folder contains the `.java` files with the solutions for that list
- Commit history that shows my progress list by list

## Requirements

- [JDK](https://adoptium.net/) 17 or higher

Check your installation:

```bash
java -version
javac -version
```

## Running locally

No build tool is needed.

```bash
git clone https://github.com/rafaelcarvalho-dev/java-exercises.git
cd java-exercises
```

Then compile and run any exercise:

```bash
cd list-01
javac ExerciseName.java
java ExerciseName
```

> Replace `ExerciseName` with the name of the file you want to run.
